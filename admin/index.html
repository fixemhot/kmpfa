소식 관리

소식 게시판에 글을 쓰고 고치는 관리자 화면입니다. GitHub에서 발급한 관리 열쇠(토큰)로 들어옵니다.

관리 열쇠 만드는 법 (처음 한 번)
  1. GitHub에 fixemhot 계정으로 로그인한 상태에서 아래 버튼을 누릅니다. 이름·기간·권한이 미리 채워진 화면이 열립니다.
    토큰 만들기 화면 열기 ↗
  2. Repository access에서 Only select repositories를 고르고 fixemhot/kmpfa 하나만 선택합니다.
  3. Permissions에 Contents: Read and write가 들어 있는지 확인합니다. (Metadata: Read-only는 자동으로 붙습니다)
  4. 맨 아래 Generate token을 누르고, 나온 문자열을 복사해 위 칸에 붙여 넣습니다.

이 열쇠는 홈페이지 파일만 고칠 수 있고 1년 뒤 만료됩니다. 잃어버리거나 유출이 의심되면 GitHub 설정 › Developer settings › Personal access tokens에서 바로 삭제하고 새로 만드세요. 열쇠는 이 브라우저에만 저장되며 GitHub 외 다른 곳으로 보내지지 않습니다.
